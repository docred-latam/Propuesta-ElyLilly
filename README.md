# Propuesta Eli Lilly · Lilly 360 · Prototipo navegable

Prototipo de interfaz para una plataforma de contenido médico. Aproximación de mockups con
imágenes de referencia; no es una propuesta definitiva ni un producto real.

- Abrir `index.html` o la página publicada. Selector de dispositivo arriba: iPhone, iPad, escritorio.
- Pantalla directa por URL: `?d=iphone&p=tema&e=diabetes` (`p`: inicio · tema · detalle · formacion ·
  pieza · guardados · perfil; `e`: diabetes · mama · derma).
- El código vive en `src/` y `build.sh` genera `index.html`.
